# 📚 LUKA 독서 캘린더

LUKA(2018년생, 초2)의 독서 기록 웹앱. 단일 HTML 파일 하나로 동작하고, 기록은 그 기기의 브라우저 `localStorage`에만 저장된다. 서버·계정·외부 전송 없음.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (HTML+CSS+JS 한 파일, 외부 라이브러리·폰트 없음) |
| `app-icon-180.png` · `app-icon-192.png` · `app-icon-512.png` | 홈 화면 아이콘 (애플/안드로이드/마스커블 공용) |
| `app-icon.svg` | 아이콘 원본 벡터 (책 세 권 모양) |
| `manifest.webmanifest` | 웹앱 설치용 매니페스트 (이름·테마색·아이콘) |

## 쓰는 법 (갤럭시탭 S9)

1. `index.html`을 태블릿 `Download` 폴더에 넣고 `내 파일` 앱에서 연다. (한 번 열면 이후엔 브라우저 최근 기록에서 바로 열 수 있다.)
2. 홈 화면에 두려면 `내 파일`에서 파일을 길게 눌러 **홈 화면에 추가**.
3. 기록은 브라우저 저장소에 남으므로 **같은 브라우저로 같은 파일**을 열어야 이어진다. 브라우저 데이터를 지우면 기록도 지워진다 → 가끔 ⋮ → 백업 내보내기.

## 탭

- **월간** — 달력. 날짜를 누르면 그날 책 목록과 `＋ 책 기록하기`. 점 = 권수, 작은 배지 숫자 = 쪽수, 오늘은 파란 날짜 칩.
- **연간** — 12개월 카드(권수/쪽수 토글, 한글=파랑·영어=빨강 비율 게이지), 월을 누르면 그 달 월간으로 이동. 아래 3칸 요약(읽은 날·가장 많이 읽은 달·가장 많이 읽은 날).
- **내 책장** — 검색·월별 보기·수정·삭제. 책마다 한글=파랑, 영어=코랄 미니 표지.
- **추천** — 초2·3~4단계 눈높이 목록 5묶음 32권. `＋ 담기` 한 번으로 오늘 날짜에 기록.

필터(`전체 / 한글책 / 영어책`)는 네 탭 모두에 함께 걸린다.

## 책 수준 (초2 · 3~4단계)

- **한글 창작동화·장편** 150~200쪽대 — 《고양이 해결사 깜냥》, 《만복이네 떡집》, 《수상한 아파트》, 《푸른 사자 와니니》, 《이상한 과자 가게 전천당》, 《긴긴밤》 등. 유아 그림책은 넣지 않는다.
- **한글 모험·판타지 시리즈** — 《마법의 시간여행》, 《꼬마 흡혈귀》, 《오즈의 마법사》 등.
- **한글 지식·과학·역사** — 《Why?》 시리즈, 《설민석의 한국사 대모험》, 《만화로 보는 그리스 로마 신화》, 《초등학생이 알아야 할 우주 100가지》 등.
- **영어** AR 2.5~3.2 — 그림이 많고 장이 짧은 책만. 브릿지 리더스 《Henry and Mudge》, 《Poppleton》, 《Nate the Great》, 《Mercy Watson》, 《Frog and Toad》 / 챕터북 《Owl Diaries》, 《Press Start!》, 《Dragon Masters》, 《Magic Tree House #1~4》. (《Diary of a Wimpy Kid》처럼 글자가 빽빽한 책은 뺐다.)

추천 카드의 쪽수는 대략값이라 담은 뒤 고쳐도 된다.

## 데이터·백업

- 저장 위치: `localStorage` 키 `lukaReadingCalendar.v1`.
- ⋮ 메뉴: 백업 내보내기(JSON) / 백업 불러오기 / 샘플 데이터 채우기·지우기 / 전체 초기화.
- 앱은 **빈 상태로 시작**한다. 시안·설명용 기록은 ⋮ → `샘플 데이터 채우기`로 넣는다(38권, 초2 수준 도서).

## 홈 화면 아이콘·매니페스트

`<head>`에 `manifest.webmanifest`와 `app-icon-*.png`를 연결해 두었다.

- `file://`로 열면 매니페스트는 브라우저가 읽지 않는다. 이때는 아이콘 파일을 `내 파일`에서 직접 골라 바로가기를 만들거나, 삼성 인터넷의 "홈 화면에 추가"를 쓰면 된다.
- `http(s)`로 올리면 크롬이 "앱 설치"로 인식해 매니페스트의 아이콘·이름·테마색(`#f1f5f9`)을 그대로 쓴다.

## 디자인

모던 쿨 톤으로 통일했다. 배경은 소프트 슬레이트·아이스 블루 그라디언트(`#f8fafc` → `#eef2fb` → `#e9eefc`), 카드는 순백에 얇은 테두리, 포인트는 코발트 블루(`#2563eb`)=한글, 코랄 로즈(`#e11d48`)=영어, 딥 인디고(`#1e293b`)=구조(탭·통계 패널·버튼).

- **통계 히어로** — 딥 인디고 패널에 큰 숫자(tabular-nums)·한글/영어 분할 게이지·인라인 요약.
- **월간 달력** — 헤어라인 그리드, 읽은 날은 언어별 은은한 틴트, 날짜 아래 도트(권수)와 쪽수 배지, 오늘은 파란 날짜 칩.
- **연간 카드** — 12개월 타일(성취도 틴트·이번 달 링·2색 게이지), 아래 3칸 요약은 아이콘+구분선.
- **책장·추천** — 한글=블루, 영어=코랄 그라디언트 미니 표지와 쪽수·단계 칩.

## 배포

GitHub Pages(활성화 후): **https://yuuunjk.github.io/reading-calendar/** — 저장소 `yuuunjk/reading-calendar`, `main` 브랜치 루트.

- 설정 → Pages → Source: **Deploy from a branch** → Branch: **main**, 폴더 **/(root)** → Save. 1분 뒤 주소가 살아난다.

- 공개 주소라 누구나 앱 화면을 열 수 있다. 다만 앱은 기록을 서버로 보내지 않으므로 **읽은 책 데이터는 각자 브라우저 안에만** 남는다.
- 수정한 `index.html`을 올리면 1~2분 뒤 주소에 반영된다.

## 개발

앱은 의존성 없는 단일 파일이라 브라우저에서 바로 열어 고치면 된다. 검증·시안 스크린샷 스크립트(`test_app.py` 61체크, `shots.py`)는 작업 폴더에만 두고 이 저장소에는 올리지 않는다.

검증 범위: 탭·필터·연간↔월간 이동·하루 보기·추가/수정/삭제·검색·백업 내보내기/불러오기·새로고침 유지·추천 담기, 초2·3~4단계 도서 구성, 디자인 디테일(성취도 틴트·분할 게이지·쪽수 배지·표지 색), 390×844와 1280×800에서 콘솔 에러 0건·가로 스크롤 없음.
